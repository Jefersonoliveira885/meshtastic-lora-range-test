GUIA DE USO — ENSAIO DE DISTÂNCIA COM MESHTASTIC RANGE TEST
Heltec V3 — Nó 01 emissor com celular / Nó 02 receptor com computador

======================================================================
1. ARQUIVOS
======================================================================

receptor_range_test_meshtastic.py
    Programa conectado ao Nó 02 por USB.

requirements.txt
    Dependência Python necessária.

Ao executar, o programa cria:

resultados_range_test\pacotes_brutos.csv
    Todos os pacotes RANGE_TEST recebidos, inclusive durante deslocamentos.

resultados_range_test\resultado_detalhado.csv
    Exatamente 30 linhas por distância.
    Pacotes perdidos aparecem com recebida=NAO e RSSI/SNR vazios.

resultados_range_test\resumo_por_distancia.csv
    PDR, PER, RSSI, SNR, sequências perdidas e desvios.

resultados_range_test\metadados_ensaio.txt
    Configuração básica utilizada na execução.


======================================================================
2. MONTAGEM DOS EQUIPAMENTOS
======================================================================

CELULAR ANDROID
    |
    | Bluetooth
    v
HELTEC V3 — NÓ 01 EMISSOR FIXO
    |
    | LoRa
    v
HELTEC V3 — NÓ 02 RECEPTOR MÓVEL
    |
    | USB
    v
NOTEBOOK/COMPUTADOR EXECUTANDO O PYTHON

O celular só configura o Nó 01.
Depois de configurado, o Nó 01 envia sozinho a cada 30 segundos.


======================================================================
3. ANTES DE CONFIGURAR
======================================================================

Nos dois nós, confira:

- mesma região LoRa;
- mesmo modem preset;
- mesmo canal primário;
- mesma chave/PSK do canal;
- mesma frequência/slot quando aplicável;
- antenas adequadas à frequência;
- MQTT desativado;
- firmware compatível e preferencialmente igual;
- bateria suficiente.

Para o ensaio descrito neste projeto:

- Preset: Long Fast;
- intervalo: 30 segundos;
- mensagens por ponto: 30;
- distâncias:
  0, 100, 200, 500, 750, 1000, 1500, 2000 e 3000 m.

IMPORTANTE:
O Range Test usa pacotes sequenciais "seq N".
O firmware configura esses pacotes com hop limit 0, portanto o ensaio é
destinado à comunicação direta entre os dois nós.


======================================================================
4. CONFIGURAÇÃO DO NÓ 01 — EMISSOR FIXO
======================================================================

1. Ligue o Nó 01.
2. Conecte o celular ao Nó 01 pelo aplicativo Meshtastic.
3. Abra:
   Configurações > Range Test
4. Configure:

   Range Test enabled / Habilitado: ATIVADO
   Sender message interval: 30
   Save CSV in storage: DESATIVADO
   Clear on reboot: DESATIVADO

5. Salve/envie a configuração.
6. Confira se o Nó 01 começa a emitir mensagens "seq N".
7. Mantenha o Nó 01 fixo no ponto de origem.
8. O celular pode continuar conectado ou ser desconectado.

NÃO DESLIGUE OU REINICIE O NÓ 01 DURANTE O ENSAIO.
Se ele reiniciar, a sequência pode voltar ao início e o ponto deverá ser repetido.


======================================================================
5. CONFIGURAÇÃO DO NÓ 02 — RECEPTOR MÓVEL
======================================================================

1. Conecte temporariamente o celular ao Nó 02.
2. Abra:
   Configurações > Range Test
3. Configure:

   Range Test enabled / Habilitado: ATIVADO
   Sender message interval: 0
   Save CSV in storage: DESATIVADO
   Clear on reboot: DESATIVADO

4. Salve/envie a configuração.
5. Desconecte o celular do Nó 02.
6. Conecte o Nó 02 ao notebook por USB.
7. Deixe o Nó 02 alimentado pelo USB durante todo o ensaio.


======================================================================
6. DESATIVAR MQTT
======================================================================

Em cada nó:

Configurações > MQTT

MQTT enabled: DESATIVADO

O código ignora pacotes via MQTT por padrão, mas o correto é desativá-lo nos
dois nós para garantir que o resultado represente somente a comunicação LoRa.


======================================================================
7. INSTALAR O PYTHON E A BIBLIOTECA
======================================================================

No Windows, instale Python 3 e marque:

Add Python to PATH

Depois, abra o PowerShell na pasta dos arquivos e execute:

py -m venv .venv
.venv\Scripts\activate
py -m pip install --upgrade pip
py -m pip install --upgrade "meshtastic[cli]"

Para confirmar:

meshtastic --version


======================================================================
8. DESCOBRIR A PORTA COM DO NÓ 02
======================================================================

Conecte somente o Nó 02 ao computador e execute:

py -m serial.tools.list_ports

Exemplo:

COM5 - Silicon Labs CP210x USB to UART Bridge

Nesse exemplo, a porta será COM5.


======================================================================
9. DESCOBRIR O ID DO NÓ 01
======================================================================

O ID pode ser visto na lista de nós do aplicativo Meshtastic.

Formato esperado:

!a1b2c3d4

É recomendado informar esse ID ao programa para ignorar mensagens de outros
nós que estejam executando Range Test.


======================================================================
10. TESTAR O CÓDIGO SEM CONECTAR O HELTEC
======================================================================

Execute:

py receptor_range_test_meshtastic.py --self-test

Resultado esperado:

SELF-TEST: todos os testes internos foram aprovados.


======================================================================
11. INICIAR O PROGRAMA NO NÓ 02
======================================================================

Exemplo:

py receptor_range_test_meshtastic.py --port COM5 --sender !a1b2c3d4

Troque:

COM5
    pela porta real do Nó 02.

!a1b2c3d4
    pelo ID real do Nó 01.

Comando completo explícito:

py receptor_range_test_meshtastic.py ^
  --port COM5 ^
  --sender !a1b2c3d4 ^
  --interval 30 ^
  --count 30 ^
  --distances 0 100 200 500 750 1000 1500 2000 3000 ^
  --output-dir resultados_range_test

No PowerShell, também pode colocar tudo em uma única linha.


======================================================================
12. SINCRONIZAÇÃO INICIAL
======================================================================

Ao iniciar, aparecerá:

Aguardando um pacote RANGE_TEST_APP válido para sincronizar a sequência...

Mantenha os dois nós próximos até aparecer algo como:

[DESLOCAMENTO] seq=15 | RSSI=-52 dBm | SNR=10,5 dB
Sincronização obtida. Última sequência recebida: 15

O programa precisa receber pelo menos uma sequência antes do primeiro ponto.
Isso permite calcular quais serão as próximas 30 transmissões.


======================================================================
13. EXECUÇÃO EM CADA DISTÂNCIA
======================================================================

O programa apresentará:

PRÓXIMO PONTO: 0 m

Procedimento:

1. Posicione o Nó 02.
2. Pare completamente.
3. Coloque a antena na altura e orientação definidas.
4. Pressione ENTER.
5. Não movimente o Nó 02.
6. Aguarde o programa concluir a janela.

Exemplo:

TESTE INICIADO: 100 m
Janela fixa: seq 46 até seq 75

A janela inclui exatamente 30 sequências:

46, 47, 48, ..., 75

Se não chegarem 48, 59 e 74, o resultado será:

Enviadas: 30
Recebidas: 27
Perdidas: 3
PDR: 90%
PER: 10%

O programa NÃO espera receber 30 pacotes.
Ele avalia 30 sequências transmitidas, evitando esconder as perdas.


======================================================================
14. DESLOCAMENTO ENTRE PONTOS
======================================================================

Depois que um ponto termina, aparece:

Agora você pode iniciar o deslocamento para o próximo ponto.

Durante o deslocamento, o Nó 01 continua transmitindo normalmente.

Os pacotes recebidos nesse período são gravados em:

pacotes_brutos.csv

com:

estado_receptor = DESLOCAMENTO
considerado_no_teste = NAO

Eles não entram nos cálculos do ponto anterior nem do ponto seguinte.

Ao chegar ao próximo ponto, pressione ENTER novamente.


======================================================================
15. COMO O PROGRAMA DEFINE O INÍCIO DA JANELA
======================================================================

O programa conhece:

- a última sequência recebida;
- o instante em que ela chegou;
- o intervalo configurado no Nó 01, por padrão 30 segundos.

Ao pressionar ENTER, calcula a primeira sequência prevista após esse instante.

Isso permite contabilizar uma perda logo no início da janela.

Exemplo:

Última sequência recebida: 100
Você pressiona ENTER antes da próxima transmissão.
Janela prevista: 101 até 130.

Mesmo que a sequência 101 não chegue, ela será registrada como perdida.


======================================================================
16. HORÁRIOS NO CSV
======================================================================

O Range Test envia somente:

seq N

Ele não envia o horário exato do Nó 01.

Por isso:

horario_envio_estimado_local
    É estimado pelo intervalo e pela sequência.

horario_recebimento_pc_local
    É o horário real em que o programa recebeu o pacote pelo Nó 02.

rx_time_radio_local
    É convertido do campo rxTime quando o firmware fornece esse valor.

RSSI e SNR
    São os valores medidos pelo rádio do Nó 02.

Não interprete a diferença entre horário estimado e horário recebido como
latência exata da comunicação.


======================================================================
17. CSV DETALHADO
======================================================================

O arquivo resultado_detalhado.csv terá 270 linhas:

9 distâncias x 30 transmissões = 270 linhas.

Exemplo recebido:

distancia_m=500
ordem_no_teste=12
sequencia_range=182
recebida=SIM
rx_rssi_dbm=-96
rx_snr_db=3,75

Exemplo perdido:

distancia_m=500
ordem_no_teste=13
sequencia_range=183
recebida=NAO
rx_rssi_dbm=
rx_snr_db=


======================================================================
18. ENCERRAMENTO DO ENSAIO
======================================================================

Após 3000 m, o programa informa os caminhos dos arquivos.

Depois:

1. volte ao Nó 01;
2. conecte o celular;
3. abra Configurações > Range Test;
4. configure Sender message interval = 0;
5. desative Range Test enabled;
6. salve;
7. faça o mesmo no Nó 02.

Não deixe o módulo ativo após o ensaio, pois ele ocupa tempo de transmissão.


======================================================================
19. CUIDADOS METODOLÓGICOS
======================================================================

Mantenha constantes:

- preset;
- região;
- potência de transmissão;
- canal;
- antenas;
- altura das antenas;
- orientação;
- tamanho/forma do equipamento;
- intervalo de 30 s;
- posição do Nó 01.

Registre em campo:

- data;
- horário;
- clima;
- obstáculos;
- linha de visada;
- coordenadas;
- altura;
- tensão/bateria;
- observações de cada ponto.

No ponto chamado 0 m, não encoste as antenas.
Use uma pequena separação física definida e registre essa distância real.


======================================================================
20. ERROS COMUNS
======================================================================

ERRO: No module named meshtastic

Solução:
py -m pip install --upgrade "meshtastic[cli]"


ERRO: porta COM ocupada

Feche:
- aplicativo Web Meshtastic;
- monitor serial;
- flasher;
- outro terminal usando a mesma COM.


NÃO RECEBE RANGE_TEST_APP

Confira:
- Range Test habilitado nos dois nós;
- sender=30 no Nó 01;
- sender=0 no Nó 02;
- mesmo canal e chave;
- mesma região/preset;
- ID do Nó 01 informado corretamente;
- MQTT desativado;
- antenas conectadas.


SEQUÊNCIA REINICIOU

O Nó 01 provavelmente reiniciou.
Repita o ponto afetado e mantenha o emissor alimentado.

21. COMANDO RECOMENDADO FINAL
======================================================================

py receptor_range_test_meshtastic.py --port COM5 --sender !a1b2c3d4 --interval 30 --count 30 --distances 0 100 200 500 750 1000 1500 2000 3000 --output-dir resultados_range_test
